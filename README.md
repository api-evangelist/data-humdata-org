# Humanitarian Data Exchange (data-humdata-org)

Humanitarian Data Exchange is a organization open-data portal running **CKAN**, exposing a standardized catalog API over ~27,880 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-humdata-org/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=data-humdata-org-api-evangelist&utm_content=repo)

- **kind:** organization  ·  **software:** CKAN  ·  **version:** 2.11.4

- **Humanitarian Data Exchange CKAN Action API** — base `https://data.humdata.org/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.humdata.org)
